# Security policy

TAIS Appearance is a free, open-source project maintained without charging users. The plugin does not include payment processing, commercial activation, advertising, or analytics services.

## Reporting a vulnerability

Report vulnerabilities privately through the GitHub Security Advisories feature for this repository. Do not publish exploit details before maintainers have had a reasonable opportunity to investigate and prepare a fix.

Do not include credentials, access tokens, private PDFs, Zotero databases, personal library exports, or other sensitive information in reports.

## Privacy expectations

Custom background images are processed locally. The plugin should not intentionally transmit document contents. If you identify unexpected network activity, include a minimal, redacted reproduction and the affected version.
