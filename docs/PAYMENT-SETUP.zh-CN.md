# 收款与1美元资助方案

## 许可边界
当前插件包含 Mica for Zotero 的 AGPL 衍生代码。AGPL 第10条禁止对许可证授予的权利增加限制；第4条允许对分发副本收费，但接收者仍保留许可权利。因此不能用许可证密钥把AGPL覆盖的12套内置主题设为“付费才能使用”。

本版决定：12套主题永久免费开放；1美元作为自愿一次性资助，而不是主题解锁费。若未来单独销售原创素材包，需先由律师确认素材是否真正独立于AGPL覆盖作品。

## 推荐：GitHub Sponsors
可以设置一次性 US$1 “TAIS Supporter”资助档位。回馈可为鸣谢、更新日志或可选署名，不应剥夺未付款用户的AGPL权利。

GitHub Sponsors 需要通过个人或组织审核、开启双重验证、提交税务资料，并提供支持地区内的银行账户或合资格财政托管方。官方当前说明：个人账户赞助款不收GitHub平台费；组织账户赞助可能收取最高6%。收款不是直接进入支付宝钱包。

## 支付宝
面向中国用户可申请合规支付宝商家产品。海外商户跨境收款通常需要支付宝/Alipay+及授权收单机构接入，涉及商户审核、KYC、结算账户、币种、退款和争议处理。个人收款码不等同于全球商家结账系统。

建议 GitHub Sponsors 面向国际用户，支付宝商户收款作为中国用户的额外选项。付款页面放在网站或GitHub，不把支付SDK、密钥或个人二维码嵌入Zotero插件。

## 当前尚未配置
尚无已审核的GitHub Sponsors档位、支付宝商户号、授权收单合同、托管结账链接或退款政策，因此不能声称已开通收款。不要把银行卡、支付宝密码、商户私钥或API密钥发到聊天或提交到GitHub。
