# TAIS Appearance — 사용자 가이드

## 제품 소개

TAIS Appearance는 Zotero에 일관된 Glass 외관 시스템을 제공합니다. 인터페이스 표면과 읽기 주변 환경을 조정하지만 PDF 글리프, 기본 텍스트 선택, 문서 내용 및 주석은 Zotero/PDF.js가 계속 관리합니다.

## 언어 선택

Zotero 설정 → TAIS Appearance → About → Language에서 자동( Zotero 언어 따르기), 중국어 간체, 영어, 일본어, 한국어 또는 프랑스어를 선택할 수 있습니다. 선택은 로컬에 저장됩니다.

## 외관 변경

상단에서 Light, Dark 또는 System을 선택합니다. Appearance에서 12가지 Glass 테마를 둘러보세요. 테마는 먼저 미리보기로 표시됩니다. 현재 외관과 비교한 다음 Apply 또는 Cancel을 선택합니다.

## 작업 환경

Academic Reading, Research, Writing은 되돌릴 수 있는 외관 프리셋입니다. 인용, PDF, 메모, 주석 데이터 또는 배경 이미지 파일을 변경하지 않습니다.

## 글꼴과 주석

인터페이스 텍스트와 주석 텍스트는 별도로 조정할 수 있습니다. 기본 모드는 Zotero 설정을 따릅니다. 사용자 지정 모드는 Zotero 인터페이스 또는 주석 패널만 변경하며 PDF에 포함된 글꼴은 교체하지 않습니다.

## 읽기 표면

페이지 주변 영역과 종이 표면은 별도로 제어됩니다. 주변 영역이 투명해져도 PDF 텍스트 자체가 투명해지는 것은 아닙니다. 대비 보호 기능은 실제 페이지 불투명도를 높일 수 있습니다.

## 배경 이미지

내장 Stage Mist와 그라데이션은 로컬 시각 자산입니다. 사용자 이미지는 로컬에서 처리됩니다. JPG, PNG, WebP를 지원하며 큰 이미지는 크기가 조정됩니다. TAIS 배경을 삭제해도 사용자가 선택한 원본 파일은 삭제되지 않습니다.

## 프로필과 백업

원하는 외관을 설정한 뒤 프로필을 저장하세요. 프로필에는 배경 이미지 파일이 포함되지 않습니다. 주요 업데이트 전에 설정을 내보내세요. 가져오기는 적용 전에 검증 및 변경 사항 비교를 수행합니다.

## 명령 팔레트

Ctrl+K 또는 명령 버튼을 누릅니다. 설정, 테마 또는 작업 환경을 검색합니다. 위/아래 키로 이동하고 Enter로 실행하며 Esc로 닫습니다.

## 복구

읽기 어려운 화면이 나타나면 Restore Native Zotero Appearance 또는 Safe Mode를 사용하세요. Safe Mode는 Zotero 기본 인터페이스를 복원하고 외관 설정 변경을 차단합니다.

## 호환성과 제한

검증된 환경은 Windows 11, Zotero 10.0.8, PDF.js 5.7.0입니다. 현재 Windows DWM 빌드는 macOS와 Linux를 지원하지 않습니다.

## 개인정보

배경 이미지는 로컬에서 처리됩니다. 진단 정보에는 외관 상태와 오류 표시가 포함되며 문서 본문은 포함되지 않습니다. 로그를 공유하기 전에 로컬 경로와 개인 정보를 삭제하세요.

## 무료 사용 및 라이선스

유지 관리자는 TAIS Appearance를 무료로 제공합니다. 12가지 테마와 핵심 기능은 모두에게 공개됩니다. 유료 버전, 구독, 기부, 활성화 키 또는 기능 잠금이 없습니다. 플러그인에는 결제 SDK나 상업용 활성화 서비스가 포함되지 않습니다.
