# TAIS Appearance 2.3.2 Beta

TAIS Appearance is now maintained as a free and open-source project. The maintainers do not charge users and do not collect donations or sponsorship payments.

## What changed

- Removed dormant purchase, license-key, restore-purchase, and hosted-checkout strings from all five locale dictionaries and UI catalogs.
- Removed the repository funding configuration and all payment/sponsorship calls to action.
- Clarified the free distribution policy across the five README files, product showcase, user guides, support, security, and contribution documentation.
- Preserved all 12 Glass themes and the existing appearance, typography, reading-surface, profile, background, and recovery features.
- Updated runtime version metadata to 2.3.2.

## Compatibility

Validated target: Windows 11 / Zotero 10.0.8 / PDF.js 5.7.0.

The current Windows DWM material adapter does not support macOS or Linux. This remains a Beta release; test in a separate Zotero profile and export settings before upgrading a primary profile.

## Localization

Simplified Chinese, English, Japanese, Korean, and French dictionaries pass automated coverage checks. The translations remain drafts and still require native-speaker review.

## Installation

Download `TAIS_Appearance-2.3.2.xpi` from the release assets and install it in Zotero via **Tools → Plugins → gear menu → Install Plugin From File**.
