# TAIS Appearance 使用手册（简体中文）

## 1. 产品定位

TAIS Appearance 是面向 Zotero 的 Glass 外观与阅读环境扩展。它调整 Zotero 界面表面、窗口材质、阅读页面外围、批注面板排版和背景视觉，不替换 PDF 内嵌字体，不重绘 PDF 原生字形，不修改文献、批注、笔记或附件内容。

## 2. 安装与更新

1. 从 GitHub Releases 下载与当前 Zotero 版本兼容的 `.xpi` 文件。
2. 在 Zotero 中打开“工具 → 插件”。
3. 点击插件管理器中的齿轮菜单，选择“从文件安装插件”。
4. 选择下载的 XPI，等待安装完成。
5. 建议升级前先导出 TAIS 设置，并保留上一版本 XPI。

当前原生窗口材质适配依赖 Windows DWM。已验证目标为 Windows 11、Zotero 10.0.8、PDF.js 5.7.0；macOS 与 Linux 暂不支持。其他 Zotero 版本需要单独验收。

## 3. 语言设置

进入 Zotero 设置中的 TAIS Appearance 页面，打开“关于 → 语言”。可选择自动跟随 Zotero，或手动选择简体中文、English、日本語、한국어、Français。语言词典随插件安装，运行时离线读取，不会把设置内容发送给在线翻译服务。Zotero 自身菜单及第三方插件仍由各自软件决定语言。

## 4. 外观与主题

顶部可选择浅色、深色或跟随系统。主题库提供 12 套 Glass 预设，包含六套浅色与六套深色。主题先进入预览状态；确认效果后再应用，也可以取消预览。主题预览不会修改文献数据。

## 5. 工作场景与个人方案

学术阅读、研究和写作场景是可逆的外观预设。个人方案可保存常用外观参数，支持复制、预览、导入和导出。方案文件不包含用户选择的背景图片文件；导入配置前会进行校验并显示差异。

## 6. 字体与批注

界面文字和批注文字拥有独立设置。原生模式跟随 Zotero；自定义模式只调整插件管理范围内的界面或批注文字，不改变 PDF 文件中嵌入的字体。列表字号仍可能由 Zotero 自身控制。

## 7. 阅读页面与透明度

阅读页面外围与纸面本身分开控制。外围透明不代表 PDF 文字透明。为保证长时间阅读的可读性，对比度保护可能提高纸面实际不透明度。扫描版 PDF、图片型页面和特殊 PDF 渲染场景可能呈现不同效果。

## 8. 背景图片

内置 Stage Mist 背景和自定义图片均在本地处理。当前支持 JPG、PNG、WebP；超大图片可能被缩放。删除 TAIS 背景只会删除插件保存的副本，不会删除用户原始图片。

## 9. 命令面板

使用 Ctrl+K 或界面中的命令面板入口，搜索设置、主题和工作场景。方向键移动，Enter 执行，Esc 关闭。正在输入文字时应避免触发快捷键。

## 10. 恢复与安全模式

如果界面难以辨认，可使用“恢复 Zotero 原生外观”或“安全模式”。安全模式会阻止外观写入，并优先恢复 Zotero 原生界面。不要把删除 Zotero 数据库或清空全部插件偏好作为首选恢复手段。

## 11. 隐私与诊断

自定义背景在本地处理。诊断信息用于排查外观状态和错误标记，不应包含文献正文。分享诊断前，请检查并遮盖本地路径、个人方案名称及其他隐私信息。
