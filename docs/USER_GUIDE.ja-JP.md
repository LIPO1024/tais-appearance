#TAIS Appearance — ユーザーガイド

## 何をするのか
TAIS Appearance は、一貫した Glass 外観システムを Zotero に追加します。 PDF グリフ、ネイティブ テキストの選択、ドキュメントの内容、注釈を Zotero/PDF.js の制御下に置いたまま、インターフェイスの表面と読書環境を変更します。

## 言語を選択してください
Zotero 設定 → TAIS Appearance → バージョン情報 → 言語を開きます。 [自動] (Zotero に従って)、簡体字中国語、英語、日本語、韓国語、またはフランス語を選択します。設定はローカルに保存されます。言語がすぐに更新されない場合は、設定ペインを再度開きます。

## 外観を変更する
上部にあるライト、ダーク、またはシステム コントロールを使用します。 「外観」を開いて 12 の Glass プリセットを参照します。プリセットはプレビューとして開始されます。現在の外観を比較し、相違点を検査して、適用またはキャンセルします。プレビューは確認されるまで永続的になりません。

## 作業シーン
Academic Reading、Research、Writing は、リバーシブルの外観プリセットです。外観コントロールのみを調整します。引用、PDF、メモ、注釈データ、カスタム フォント サイズ、背景画像ファイルは編集されません。

## タイポグラフィー
インターフェイス テキストと注釈テキストには独立したコントロールがあります。ネイティブ モードは Zotero に従います。カスタム モードでは、Zotero インターフェイスまたは注釈パネルのみが変更されます。 PDF に埋め込まれたフォントは置き換えられません。

## 読み取り面
ページの周囲とページの表面は分離されています。透明な周囲は、PDF テキスト自体が透明であることを意味するわけではありません。コントラストを保護すると、実際のページの不透明度が上がる場合があります。スキャンされたページ、画像、および特殊な PDF エンジンは異なって見える場合があります。

## 背景
組み込みの Stage Mist とグラデーション背景はローカルのビジュアル アセットです。カスタム イメージはローカルで処理されます。 JPG、PNG、および WebP のみが受け入れられます。特大の画像はリサイズされます。 TAIS 背景を削除すると、ユーザーが選択した元のファイルではなく、プラグインの保存されたコピーが削除されます。

## プロファイルとバックアップ
好みの外観に達したら、プロファイルを保存します。プロファイルには背景画像ファイルは含まれません。メジャー アップグレードの前に、必要なスコープをエクスポートします。インポートでは、適用する前に常に検証が行われ、相違点リストが表示されます。

## コマンドパレット
Ctrl+K を押すか、コマンド ボタンを使用します。セクション、設定、テーマ、作業シーンから検索します。 Up/Down を使用して移動し、Enter を使用して実行し、Esc を使用して閉じます。編集可能なフィールドに入力するときにショートカットを呼び出さないようにします。

## 回復
ウィンドウが読みにくくなった場合は、ネイティブ Zotero の外観を復元または Safe Mode を使用してください。 Safe Mode は、Zotero のネイティブ インターフェイスを復元し、外観の書き込みをブロックします。回復の第一段階として、Zotero データベースを削除したり、プラグイン設定をクリアしたりしないでください。

## 互換性と既知の制限
検証済みのターゲットは、Zotero 10.0.8 および PDF.js 5.7.0 を備えた Windows 11 です。 macOS と Linux は、この Windows DWM ビルドではサポートされていません。 PDF ピクセル、選択、コピー、印刷、マルチモニター、長時間、およびサードパーティのプラグインのテストは、現在のリリースの QA レポートと照合してチェックする必要があります。

## プライバシー
背景画像はローカルで処理されます。診断には、ドキュメントのテキストではなく、外観の状態とエラー マーカーが含まれます。ログを共有する前に、パス、プロファイル名、その他の個人情報を編集します。
