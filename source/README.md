# TAIS Appearance 2.2.1

**Theatre AI Studio · TAIS**

让研究，更从容。为 Zotero 提供可调整、可预览、可恢复的外观与阅读环境。

## 本版
- 单行产品标题与精简文案；命令面板、预览和恢复逻辑保留。
- 原创舞台框／T标识，9种原生像素尺寸。
- 12套Glass主题：清透、柔光、舞台、专业；各3套，6浅色与6深色。
- 舞台雾光：安静中央与柔和侧光，浅深双版，离线静态矢量。
- 宣传展示页与图文手册在对应交付包的showcase/与docs/目录；真实截图与参数示意明确区分。

## 使用
Zotero设置 → TAIS 外观。主题/场景/个人方案先预览；确认提交，取消恢复。Ctrl+K打开命令面板。原有设置、方案、背景副本和插件ID不迁移。

## 边界
当前本机验收环境Windows 11／Zotero 10.0.8／PDF.js 5.7.0。本版不写入文献、笔记或批注；不重画PDF字形。透明度与舒适度受显示环境影响。完整测试范围与未验证项在验收报告中列出。未建立公开发行渠道，不冒充跨平台Stable。

## 构建与许可
安装requirements-build.txt后执行python build.py。每个测试套件必须存在且通过。公开构建仍要求真实HTTPS更新/下载/源码/支持地址及许可审查。保留LICENSE和NOTICE；原始Mica衍生代码的对应源码复核仍为公开发行条件。
