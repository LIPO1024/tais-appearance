# Community support

The TAIS maintainers provide the plugin and documentation free of charge. There are no paid support plans or priority support tiers.

For help:

1. Read the five-language user guides linked from the repository README.
2. Search existing [GitHub Issues](https://github.com/LIPO1024/tais-appearance/issues).
3. If the issue is new, open an issue with the plugin version, Zotero version, Windows version, reproduction steps, and expected/actual behavior.
4. When relevant, test in Safe Mode and attach a redacted diagnostic report.

Do not attach your Zotero database, private PDFs, access tokens, personal library exports, or unredacted local paths.

Community support is provided through public documentation and issue discussions. No payment is required.
